# The point of this board is the mainline media stack, and none of it can be
# checked from a serial console without v4l2-ctl.  In Gentoo that lives in
# media-libs/libv4l (the old media-tv/v4l-utils is blocked by it), behind the
# `utils` USE flag, which is on by default.  It answers the only question that
# matters on first boot:
#   v4l2-ctl --list-devices | grep -A2 snps_hdmirx
media-libs/libv4l

# Mesa for the Mali-G610: panfrost GL + panvk Vulkan.  VIDEO_CARDS is written
# into the crossdev prefix by pre-deps.sh.  Cross-emerge of mesa is not proven
# yet; dropping this line leaves a bootable image with the kernel-side GPU,
# NPU and VPU drivers still in place.
media-libs/mesa
